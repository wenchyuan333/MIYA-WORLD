## 一、判定基準（先封閉）

迴文數的定義是：`n` 在 base `b` 的數字串 `a_k ... a_0` 滿足 `a_i = a_{k-i}`。

這個定義引用了「表示」。因此：

```
迴文性 = 表示層性質（REPR），不是數本身的性質
證據：333 十進位迴文；333 = 101001101 二進位，非迴文
      13  十進位非迴文；13  = 111 三進位，迴文
```

依上一輪已立的判準「換單位就消失的，不是性質」，迴文性與 `333 m` / `333 K` / `333 度`
屬同一類層問題：**它是關於書寫方式的斷言，不是關於對象的斷言。**

因此本次分級只有一個問題：
**有沒有哪一條迴文性質，在換基底之後仍然對應同一個結構物件？**

有，而且只有一條。

## 二、唯一入口（內涵，TESTED）

```
111_q = q^2 + q + 1 = |PG(2,q)|          [INDEX]

q=2  ->  7   Fano 平面
q=3  ->  13  本系統
q=4  ->  21
q=5  ->  31
q=7  ->  57
q=8  ->  73
q=9  ->  91
```

對每個質數冪 `q`，射影平面的點數在 base `q` 恆為 `111`，恆為迴文。

這條之所以是內涵而非外衣：**基底不是外加的單位，基底就是 `q` 本身。**
`111_q` 的三個 `1` 對應 `sigma(q^2) = 1 + q + q^2` 的三項，也就是
維度 0、1、2 的子空間計數。換 `q` 不會讓性質消失，只會換到另一個射影平面。

對本系統：

```
13 = 111_3 = (3^3 - 1) / (3 - 1) = |PG(2,3)|
上一輪已證：PG(2,3) 移除 l_inf 得 AG(2,3) = 洛書格，13 = 9 + 4
```

## 三、第二條內涵：13 在群層的來源（TESTED）

```
|GL(3,F3)|  = 11232    = 2^5 x 3^3 x 13
|GL(4,F3)|  = 24261120 = 2^9 x 3^6 x 5 x 13
11232 / 13 = 864

|PGL(3,3)| = 11232 / 2 = 5616
5616 = 13 x 432
432  = |GL(2,3)| x 9 = 48 x 9 = |AGL(2,3)|
```

這關閉了上一輪的一個未問之問：**為什麼障礙定理要窮舉 432 個仿射映射，剛好 432？**

```
PGL(3,3) 傳遞作用於 PG(2,3) 的 13 條線
任一條線 l_inf 的穩定子群 = AGL(2,3)，階 432
指數 = 5616 / 432 = 13 = 線數
=> 上一輪的窮舉範圍恰為一條線的完整穩定子群。無遺漏，無多餘。
```

並且 `13` 出現在 `|GL(3,F3)|` 的因數分解中不是算術巧合：它是 **Singer cycle**，
即 `PGL(3,3)` 中一個 13 階元素，正則地循環 13 個點。

對照上一輪的 333 體檢：

```
gcd(333, 11232) = 9     平凡，9 是 3^2，兩邊都有
13 | 11232              非平凡，來源是 Singer cycle
```

**這是本次唯一升格的新結構事實。**

## 四、登記為同構、不寫等號（REPR vs INDEX）

反迴文（antipalindromic）定義：`a_i = b - 1 - a_{k-i}`，即 `a_i + a_{k-i} = b - 1`。

```
[REPR]  base 3 反迴文條件： a_i + a_{k-i} = 2
        唯一自配對數字： d + d = 2  =>  d = 1
        13 = 111_3 同時是 base-3 迴文 且 base-3 反迴文

[INDEX] 洛書對位律：       L_ij + L_{4-i,4-j} = 10
        唯一自配對索引： i + i = 10  =>  i = 5
```

兩式**形式同構**：固定和的對合配對，各有唯一不動元素。

但依憲章第 1 條與硬規則「同型不同位不得跨塊等號」：

```
1 (digit, mod 3)  !=  5 (index, 1..9)
=> 只登記同構，不寫等號，不用其中一邊證另一邊
```

狀態：`FORMAL_MODEL`（形式同構已驗）／不得升 `TESTED` 作為系統主張。

## 五、外衣清單（判定不入 kernel）
