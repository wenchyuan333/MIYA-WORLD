# 附錄一：類比層防火牆

依規則第 5 條與第 2 條，以下四份類比材料逐份分級。分級不是貶低，是防止它們被引用為前提。

分級：`ANALOGY`

結構對位正確。七道過濾層：花崗岩 / 矪沙 / 濾紙1 / 活性炭 / 濾紙1 / 石英砂 / 濾紙3。「一層一檢」與規則 A 同形。

物理安全註記：此塔去濁度、色素、异味。**不殺菌、不除溶解鹽、不除重金屬。出水不可直飲。**

不得推出：「七層」與本系統的任何層數有對應關係。塔是七，規則分八節，矩陣分三層。三個七不是同一個七。

## 2. 宇宙底層潏透

## 3. 洛書拓樸展開

分級：**展開 1 作廢（事實錯誤）**，展開 2 `SYMBOLIC`，展開 3 部分成立

### 展開 1：環面展開 —— FAIL

宣稱：貼到環面上，斷掉的對角線變連續，8 條 15 變無限條 15。

實算：

```
4 9 2
3 5 7
8 1 6

破碎對角  9, 7, 8 = 24
破碎對角  4, 7, 1 = 12
破碎對角  2, 3, 1 = 6
```

洛書**不是**泛對角幻方（pandiagonal / panmagic）。且已知定理：**3x3 泛對角幻方不存在。**

另：環面黏合後破碎對角線每方向只有 3 條，共 6 條，不是「無限條」。

→ 本展開作廢。若要保留環面語彙，只能說「三行三列在環面平移下對稱」，不得延伸到對角線。

### 展開 2：九宮疊加 —— 兩處層混用

- `P 交換 10<->13 就是洛書的 4<->6 鑑射` —— 兩者是同一個對合的不同軌道，不是同一個換位。跨塊等號。
- `1 != 2 就是拓樸破洞` —— `1 != 2` 是 F3 矩陣元素比較；`破洞` 是同調群的量。本輪未計算任何同調。

### 展開 3：到 13 點 —— 部分成立

成立：`[[0,1],[1,0]]` 直和是 PUB 對位的對蹄交換，`det = 1 mod 3`，可逆。這就是定版。

不成立：`5 = 濾紙孔徑`、`15 = 流過的水量`。無單位、無測度、無鑑別量。`SYMBOLIC`。

# 附錄二：分流閘

每一輪新增一個類比域，而沒有一個域被封閉，就是規則第 4 條在禁止的事。因此立分流閘：

```
輸入材料
  |
  +-- 有鑑別量（可能出 FAIL）?
  |     是 -> 矩陣層 -> 寫 fixture -> 綠燈 -> kernel/
  |     否 -> 類比層 -> canon/ANALOGY-LEDGER.md -> 永不作為前提
  |
  +-- 分級必寫入：ANALOGY / SYMBOLIC / IMAGINATIVE / OPEN
```

鑑別量的定義（採自魯班鎖頁）：必須存在至少兩條路徑，且兩條的原始輸入集不互相決定。由相加導出的恆等式只能回報「有錯」，不能回報「錯在哪一項」。

已存在的同型治理（不重建，直接調用）：

1. MIYA-4096 Runtime Governance Law v0.1 第 13.4 節：三門聯合裁決，任一門缺型別即 `HOLD`。
2. 魯班鎖頁第一節：`Σ Q = 0` 拆為「作主張 = 恆真句，鑑別量 = 0」與「作一致性檢查 = 成立」。
3. SEME-001：`ΔA != 0` 才算誕生。讀了等於沒讀，意義未誕生。

診断：治理機制三份都在。缺的是調用，不是新規則。
