## 二、可驗的真發現：PUB 的 F_3^4 恰好能承載四元數代數

原文 §[2] 寫：`M_Q = a + bi + cj + dk, a,b,c,d 屬於 F3`。

這句話指定了一個**完全確定、可枚舉、可機械檢查**的物件。已 fixture 化：`tools/verify_quaternion_f3.py`。

### 2.1 維度已合

以 F_3 為係數的四元數代數是 4 維的，共 `3^4 = 81` 個元素。
**這恰好就是 PUB 層 F_3^4。** 不是類比，是同一個集合大小。

### 2.2 Q8 的乘法關係在 F_3 上真的成立

`i2 = j2 = k2 = ijk = -1`、`ij = k`、`ji = -k`、非交換、Q8 對乘法封閉、八個元素範數均為 1。
全部驗過。原文 §[2] 第一行是對的。

### 2.3 ❗ 但它**不是**除環——這是反直覺的部分

實數四元數是除環（每個非零元可逆）。。**在特征 3 下這件事失效。**

具體反例（已入 fixture）：

```
q = 1 + i + j
N(q) = 1 + 1 + 1 = 3 = 0 mod 3
q 乘 conj(q) = 0
```

兩個都不是零的元素相乘得 0。所以 `q` 沒有逆元（已枚舉全部 81 個元素確認）。

### 2.4 單位群阶恰為 48

枚舉全部 81 個元素，可逆者 48 個、不可逆者 33 個。

而 `|GL(2,F_3)| = (9-1)(9-3) = 8 x 6 = 48`。

**两个 48 相等。** 這強烈指向一件標準代數事實：有限體上的四元數代數都是**分裂**的，同構於 2x2 矩陣代數。

❗ 但本腦本**只驗了必要從屬**（有零因子 + 單位群阶相等），**沒有建構出同構映射**。
所以「同構於 M_2(F_3)」仍標 `[SKIP]`，不得寫成已驗。

### 2.5 這件事對體系的意義

如果提出人想讓 PUB 層携帶「四元數結構」，那麼他可以。但得接受一個代價：

> 那個結構裡有 33 個不可逆元。PUB 層不是一個「每個非零態都可逆」的層。

這與 HEARTBEAT-V13 的 `pub_det != 0` 條件相容（那條本來就是在排除奇異情況），
但它證明了**那條條件不是冗詞**：在 4 維 F_3 里，奇異是常態（33/81 超過四分之一）。

## 三、四處型別錯置（必須修）

### 3.1 「連續化：M_Q → exp(Q) 屬於 SU(2)」—— exp 在 F_3 上未定義

`exp` 需要無窮級數、需要極限、需要整數可除（`1/n!`）。
F_3 是特征 3 的有限體：沒有極限，且 `3! = 6 = 0 mod 3` 不可除。
**在 F_3 係數上寫 `exp` 是沒有意義的。**

可以保住的正確陈述是：

> Q8 作為抽象群，確實可以嵌入 SU(2)（它就是 SU(2) 的 8 阶有限子群）。

但那是**群的嵌入**，與 F_3 係數完全無關。兩條路：

- 要走 SU(2)：丟採 F_3，在特征 0 裡做
- 要走 F_3：丟採 exp 與連續化，做有限群

**不能兩邊同時抽。** 這與提出人自己寫的「索引層 ≠ 矩陣層」是**同一個病灶的不同衣服**：
這次是「特征 3 ≠ 特征 0」。

### 3.2 O1 現在有兩個互斥的定義

| 來源 | O1 是什麼 | 半徑 |
| --- | --- | --- |
| `canon/ORIGIN-FIELD-THEORY-v0.7.2.md` | 原點，`ker(π)`，中宮 | 洛書部分寫 `r5 = 0` |
| V13.1 §[1] | 第一軌道，`r_isco` | 施瓦西德情況下 `r_isco = 6M`，非零 |

一個是半徑 0 的點，一個是半徑 6M 的軌道。**這兩個不能同時是 O1。**
須提出人裁示：改名其中一個，或明言兩者屬不同層且不得互相代入。

### 3.3 閉環式 `番_Luoshu zeta(s) Q M dr = 0` 不是一個數學命題

被積函數里同時出現：

- `zeta(s)`：複平面上的解析函數（特征 0）
- `Q`、`M`：F_3 上的代數物（特征 3）
- `dr`：實數測度

F_3 上沒有極限、沒有測度、沒有積分。
**這不是「尚未証明的式子」，而是「尚未成為式子的符號串」。**
它可以作為意向保留（「我想要一個把這三者接起來的東西」），但 CLAIM CEILING 只能是 `IMAGINATIVE`。

若要往上走，最小的第一步是：把三個物件放到**同一個範疇**里。目前連那一步都未開始。

### 3.4 `eta = pi / sqrt(18)` 是**三維**值，標題寫的是「六角」

| 維度 | 最密堆積 | 值 |
| --- | --- | --- |
| 三維 FCC / HCP | `pi / sqrt(18) = pi / (3 sqrt2)` | 0.74048 |
| 二維六角 | `pi / sqrt(12)` | 0.9069 |

原文寫 `hex = densest packing, eta = pi/sqrt(18) 約 0.74048` —— **數值是對的，但它是三維的。**
二維六角堆積是 0.9069。兩個值已入 fixture 並驗過不相等。
須標明維度，否則此處歧義。
（順帶：HCP 確實可以描述為「六角」，所以這不是錯，是**不完整**。）

## 五、OPEN ISSUES

1. **O1 的兩個定義必須收成一個**（`r = 0` 的原點 vs `r_isco` 的軌道）。這是本次審查最優先的一項。
2. **「六角黑洞」缺定義**。Kerr-Newman 外視界在球對稱坐標下是旋轉對稱的，不是六角形的。若指的是其他意思（例如多黑洞六角排列），須明言。
3. **eta 的維度須標明**（3D 0.74048 vs 2D 0.9069）。
4. **F_3 四元數代數與 M_2(F_3) 的同構映射未建構**。已驗兩條必要從屬，同構本身仍 `[SKIP]`。
5. **四元數代數與 13 維對位律的關係未建立**。它坐在 PUB 的 4 維上（大小吹合），但「大小相等」不是「結構相容」。須別驗：對位置換 P 限制到 PUB 區後，是不是四元數代數的自同構？**這一條目前完全未驗。**
