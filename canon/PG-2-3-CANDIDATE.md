## 1. 起點：一個恨等式

```
sigma(3^2) = 1 + 3 + 9 = 13
(3^3 - 1) / (3 - 1) = 26 / 2 = 13
```

這兩个 13 是同一个 13，而且它就是 `|PG(2,3)|`。

## 2. 事實層（教科書，`TESTED`）

```

           每線 q + 1 點，每點 q + 1 線

q = 3：13 點，13 線，每線 4 點，每點 4 線

移除任一條線 l_inf（4 個點）
```

## 3. 主張：`13 = 9 + 4` 不是分配

**舊狀態**：`V13 = 13 點`，`核區 = 9`，`PUB = 4`。為何是 9 與 4？無答。`13 = 4 + 9` 是分配。

**新狀態**：若 13 點識別為 `PG(2,3)` 的 13 點，則

```
9 = |AG(2,3)|      自動排成 3x3，即洛書格
4 = |l_inf| = q+1  即 4 個方向：行、列、對角、反對角
```

分解不再自由。分級：`FORMAL_MODEL`（識別本身待証，見第 6 節）。

## 5. 障礙定理：PUB 豁免律由宣告降為定理

若 PUB 四格 = `l_inf` 四方向，則核區對位與 PUB 對位應來自同一個幾何對合。

### 定理

不存在 `AG(2,3)` 的仿射對合 sigma 同時滿足：

- (a) 9 個點中只固定中心
- (b) 4 個方向作 2+2 對換

### 証明

```
sigma(x) = A x + b，A 屬 GL(2,3)，b 屬 F3^2
sigma^2 = id  =>  A^2 = I  且  (A + I) b = 0

條件 (a)：固定點方程 (A - I) x = -b 有唯一解
  =>  A - I 可逆
  =>  A 無特征值 1

A^2 = I 且 char 3 != 2  =>  A 可對角化，特征值屬 {1, -1}
無特征值 1        =>  A = -I

A = -I 對方向（1 維子空間）的作用是平凡的
  因為 -v 與 v 生成同一條線
  =>  sigma 固定全部 4 個方向
  =>  條件 (b) 不可能
```

### 推訖

**「PUB 豁免核律」不是隨手加的例外，是被迫的。** 兩個對位在幾何上不可能同源。

這是本倉庫第一條由「宣告成立」還原為「定理成立」的規則。分級：`FORMAL_MODEL`，待 fixture 第五節窮舉確認（432 個仿射映射，可完全枚舉）。
