# canon/ 主張層級天花板（Claim Ceiling）

本目錄所有文件須在頁首宣告主張層級。未宣告者預設 `OPEN`，不得被引用為依據。

## 層級梯度

```
OPEN → IMAGINATIVE → SYMBOLIC → ANALOGY → FORMAL_MODEL
     → COMPUTABLE → TESTED → SUPPORTED → CANONICAL
```

| 層級 | 進入條件 |
| --- | --- |
| `SYMBOLIC` | 符號體系自洽，不要求可算 |
| `ANALOGY` | 與已知理論結構相似。**相似 ≠ 推導** |
| `FORMAL_MODEL` | 有完整形式定義且符號規則內部一致 |
| `COMPUTABLE` | 有可執行實作 + fixture |
| `TESTED` | fixture 已跑過且可重現，附 run 收據 |
| `SUPPORTED` | 有獨立於本倉庫的外部証據 |
| `CANONICAL` | 經驗證、納入不認清單、可被引用為前提 |

## 不可越級條款

1. **符號對應不是推導**。將一套符號映射到現有物理式子上，不等於從其公理推出那些式子。
2. **編號相鄰不是同構**。維數、阶數、項数相等或相近，不构成结构对应。
3. **不升物理真值**。未經實驗或可偽造預測驗證前，不得宣稱描述真實物理世界。
4. **不升因果**。相關、共現、結構類比均不得寫作因果語句。
5. **不升群同型**。除非給出具體同型映射並驗運算保持，不得宣稱群同構。
6. **合併 ≠ 驗證**。PR 被合併不提升任何文件的主張層級。
7. **沒有收據不算發生**。以 commit SHA / PR 編號 / run hash 為憑。

## 升格程序

升格須單獨開 PR，且 PR body 須同時列出：原層級 → 新層級、所依據的驗算或 fixture、以及本次升格未涵蓋的殘留項。
