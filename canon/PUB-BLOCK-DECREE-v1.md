## 一、F3-對位塊定理

設 2x2 塊在對位置換下不變，則它必為

```
[[a, b],
 [b, a]]
```

於是 `det = a^2 - b^2 = (a - b)(a + b)`。

在 F3 上，若 `a` 與 `b` 皆非零，則 `a, b` 屬於 `{1, 2}`，於是必然 `a = b` 或 `a = -b`，兩者皆令 `det = 0`。

> **定理**：任何在對位置換下不變的 2x2 塊，若對角元素與非對角元素皆非零，則在 F3 上必為奇異。

推論：`[[2,1],[1,2]] det = 0` 不是筆誤，是唯一可能的結果。

P 不變且可逆的 2x2 恰有四種：

| 塊 | det mod 3 | 保對角 | 保對位邊 |
| --- | --- | --- | --- |
| `[[0,1],[1,0]]` | 2 | 否 | 是 |
| `[[0,2],[2,0]]` | 2 | 否 | 是 |
| `[[2,0],[0,2]]` | 1 | 是 | 否 |
| `[[1,0],[0,1]]` | 1 | 是 | 否 |

**對角與對位邊在 F3 上不可兼得。**

## 二、裁示：保對位邊（選項甲）

```
PUB_pair_10_13 := [[0,1],[1,0]]
PUB_pair_11_12 := [[0,1],[1,0]]
pub_det := 2 * 2 = 4 = 1 mod 3
```

理由：對位邊是這個矩陣存在的理由；對角的 2 只是 `M = A - I` 這個構造習慣的副產品。若選保對角，對位律將退回純索引層，矩陣不再編碼它，整個矩陣計畫失去意義。

對角歸零後，M 是一個簡圖的鄰接矩陣，不再是 `A - I`。

## 四、硬規則新增條款

1. **零行規則**：任一列或欄全零 => `det = 0`，立即 FAIL，不展開餘因子。對任何體成立。
2. **直和規則**：`det(A 直和 B) = det(A) * det(B)`。**禁用加法**。
   - 反例：`det = 1` 與 `det = 2` 時，加法得 `0` 會誤判 FAIL，乘法得 `2` 才是真 PASS。
3. **P 不變規則**：對位塊必為 `[[a,b],[b,a]]`，兩對角元素必須相等。
4. **層分離規則**：「核區度數 3 對 3」屬**圖層**，「PUB 子矩陣 det」屬**矩陣層**。兩者獨立，不得互推。換 PUB 塊不會動到核區度數；核區度數對了也不能推出 PUB 塊合法。
5. **拄寫規則**：引用別人算出的數字時，必須同時貼出該數字對應的原始輸入。算式與輸入脇鉤 => 該結果作廢，重算。
6. **待驗值規則**：`P-10 = UNKNOWN`。`full_det` 由 fixture 印出，不 assert，不手猜。
