## 一、三兔共耳 —— 群論硬阻断（FAIL）

宣稱：中心 5 是共耳，8 宮是 3 隻兔子，(1,9,3,7) 共一耳。

### 1.1 群論阻断

```
Aut(洛書) = D4，|D4| = 8
拉格朗日定理：子群阶整除群阶
3 不整除 8  =>  D4 中不存在 3 阶元素

三兔共耳的結構本质 = C3 旋转对称

=>  三兔共耳无法实现为洛书的对称
```

同样：13 点系统的对位置换 P 阶为 2，生成 C2。也没有 3 阶元素。

### 1.2 算术也不闭

三兔共耳是 3 兔 3 耳，每耳被 2 兔共用。

- 「8 宫是 3 隻兔子」—— 8 不能被 3 整除
- 「(1,9,3,7) 共一耳」—— 4 格配一耳，与 3 兔 3 耳矛盾

### 1.3 但有一个合法落点

这个系统里确实存在 C3，只有一处：

```
(F3, +) 的加法群 同构于 C3     <- 值层

位置层：D4（洛书）、C2（P 对合）均无 3 阶元素
```

三兔共耳若要进来，**唯一合法的门是 F3 的值层**，不是九宫的位置层。
这是一个尚未被探索的方向，分级 `OPEN`，待 fixture。

## 二、仿射互壓定律 —— 反對稱化漏了一項

### 2.1 漏項

```
你写：Delta P_ij = grad_i F_j - grad_j F_i = T^k_ij F_k

实际：grad_i F_j = d_i F_j - Gamma^k_ij F_k
      Delta P_ij = (d_i F_j - d_j F_i) - T^k_ij F_k
                    ^^^^^^^^^^^^^^^^^ 外微分项，被漏掉
```

**修正後的正确陈述**：

```
Delta P_ij = (dF)_ij - T^k_ij F_k

只有当 dF = 0（F 为闭形式，局部 F = d phi）时，
Delta P_ij = - T^k_ij F_k  才成立。
```

漏掉的正是电磁场强那一项。加上 `dF = 0` 条件即可。分级 `FORMAL_MODEL`。

### 2.2 型別错误

```
你写：P_ij = - grad_i F_j + Gamma^k_ij F_k
展开：     = - d_i F_j + 2 Gamma^k_ij F_k
```

Gamma 单独出现 => **不是张量**，坐标变换下不守恒。
若意图是 `P_ij = grad_i F_j`，则直接写 `grad_i F_j` 即可。

### 2.3 对位主张全部不成立

| 宣称 | 判定 |
| --- | --- |
| `T = 0` 对位 `L_ij + L_{4-i,4-j} = 10` | 跨层。一个是微分几何的联绘（特征 0、连续、有流形），一个是索引层的整数配对 |
| `T != 0` 对位 `M[10][10] != M[13][13]` | **结构上不可能**。M 是对称矩阵，`M = M^T`，扝率的类比恒为零 |
| 同上（数值） | 定版后 `M[10][10] = M[13][13] = 0`，例子本身作废 |

`PMP != M` 的失效不是反对称性，是**非等变性**（equivariance）。两回事。

### 2.4 舍弃对称联绘的真实代价（需入帐）

保留 `T^k_ij != 0` 后：

- 派生不再是 Levi-Civita，即使度规兼容也不唯一
- 测地线（极值）与自平行线（平移）分开，不再重合
- 第一 Bianchi 恒等式改形，多出扝率项

这些都是 Einstein-Cartan 理论的正常代价，不是错误。但必須入帐。
**且本 13 点系统没有流形、没有联绘、没有切丛，所以对位本身 `OPEN`。**
