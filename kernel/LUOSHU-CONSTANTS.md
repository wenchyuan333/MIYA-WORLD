# kernel/ 洛書 L0 常量表

洛書矩陣 L0 的可驗算不變量。本文件是 `kernel/` 目錄的不動層：**只收算得出來的數**，不收詮释。

```
L0 =
  4  9  2
  3  5  7
  8  1  6
```

## 二、不得升格的項目（警語）

以下在其他文件中出現過，但**不得**視為已驗：

1. **`V4 = Z2 x Z2` 對應**。K-17 的四組對位對確實各自是對偶，但宣稱它們組成 Klein 四元群須給出具體的群運算並驗閃閃封閉性。未給出→ 層級上限 `SYMBOLIC`。
2. **中宮 5 ↔ `sigma = 1/2` ↔ `r+`**。這是三個不同領域的中點概念並列，層級 `ANALOGY`。不得寫作推導或同構。
3. **9 宮 ↔ `V_13` 的 9 維内部空間**。見 `canon/ORIGIN-FIELD-THEORY-v0.7.2.md` OPEN-ISSUE #4：目前是分配而非推導。
4. **量子干涉形式（H_9、Grover 約 3 步）**。層級 `FORMAL_MODEL`；`sqrt(9) = 3` 是步數量級估值，不是已實作的線路。
5. **`M5-LOSHU-EXTERIOR` 内外不相交**。内涵 5 元素與外衣 4 元素 `isdisjoint`，仍未收束。外衣叙事（洛書→多世界→意識→宇宙）**不在本文件範圍内**。

## 四、使用規則

1. 引用本表須連同編號與層級，例如「K-03 `det = 360`（TESTED）」。
2. 新增常量須附驗算方式；無驗算者不得進入本表，改放 `research/`。
3. 任何層級提升須單獨開 PR，且附 fixture 執行憑證。
4. 本文件不收任何需要主觀詮释的項目。
